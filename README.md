# cla-puesta-puntos-ignition-full

Implement a digital system for setup formats that unifies the automatic capture of parameters from PLCs with the manual recording of field variables, access control via Global ID, validation through dual digital signatures on-site, data export for statistical analysis, and automatic generation of PDF files by shift or batch for regulatory compliance, ensuring traceability and reliability in production processes.


## Contributions Welcome:
• Development and implementation of the following modules:
    o Digitization module for formats with hybrid (automatic and manual) data capture.
• Reading of automatic variables (from PLC) and manual inputs (visual inspection).
• Data export to Excel/CSV for external analysis.
• Implementation of alarms and reminders for manual entry by format.
• Access management through unique Global IDs.
